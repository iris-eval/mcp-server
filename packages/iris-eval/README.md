# iris-eval

This package is a placeholder for the name. [Iris](https://iris-eval.com), the MCP server that scores every agent output for quality, safety and cost, is published as [`@iris-eval/mcp-server`](https://www.npmjs.com/package/@iris-eval/mcp-server); running this package prints the commands below and exits with status 1. It has no dependencies and is not updated with the server.

```
npx -y @iris-eval/mcp-server                    # run the server
npx -y @iris-eval/mcp-server install <client>   # set up an MCP client
```

Source: [github.com/iris-eval/mcp-server](https://github.com/iris-eval/mcp-server) · MIT
